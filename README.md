# CUDA at Scale — Batch Image Edge Detection

A CUDA C++ program that performs **grayscale conversion + Sobel edge
detection** on a batch of images, entirely on the GPU. It is built for the
CUDA at Scale for the Enterprise course project and is designed to process
a large batch of small images (hundreds of 128x128 PNGs) in a single
invocation, with one kernel launch pair (grayscale + Sobel) per image and
per-image GPU timing captured via CUDA events.

## What it does

1. Scans an input directory for images (`.png`, `.jpg`, `.jpeg`, `.bmp`).
2. For each image:
   - Uploads the RGB pixel buffer to device memory.
   - Runs `RgbToGrayscaleKernel` to convert to single-channel grayscale.
   - Runs `SobelEdgeKernel` to compute the gradient magnitude (Gx, Gy) with
     a 3x3 Sobel operator and threshold it into a binary edge map.
   - Downloads and writes the result as a PNG.
3. Prints a summary: images processed, total GPU kernel time, total
   wall-clock time, and average GPU time per image.

Both kernels are hand-written CUDA (no NPP dependency), so the only
external code is the single-header [stb_image](https://github.com/nothings/stb)
libraries used purely for PNG/JPEG/BMP I/O (included in `include/`).

## Requirements

- NVIDIA GPU with a CUDA-capable driver
- CUDA Toolkit (nvcc), tested against CUDA 11.x/12.x
- A C++17-capable host compiler (g++)
- Python 3 with Pillow (`pip install pillow`), only needed if you want to
  regenerate the sample dataset

## Build

```bash
make
```

This produces `bin/edge_detect`. Edit the `ARCH` variable in the `Makefile`
(default `-arch=sm_75`) to match your GPU's compute capability if the build
fails with an unsupported-architecture error.

## Run

```bash
./bin/edge_detect --input data/input --output data/output --threshold 60 --verbose
```

### CLI arguments

| Flag           | Required | Description                                          |
|----------------|----------|-------------------------------------------------------|
| `--input`      | yes      | Directory containing input images                    |
| `--output`     | yes      | Directory to write edge-detected PNGs to              |
| `--threshold`  | no       | Gradient-magnitude threshold for an edge (default 60) |
| `--verbose`    | no       | Print per-image GPU timing                            |
| `--help`       | no       | Print usage                                           |

### One-command build + run

```bash
./run.sh
```

This regenerates sample data if `data/input/` is empty, builds the project,
runs it against the full batch, and saves a timestamped log to
`proof_of_execution/`.

## Regenerating the sample dataset

The 200 sample images in `data/input/` are already committed, but you can
regenerate a fresh (differently seeded) set with:

```bash
python3 scripts/generate_sample_data.py
```

## Notes on proof of execution

`run.sh` writes a full console log (device name, image count, per-image
timing, and summary statistics) to `proof_of_execution/run_log_<timestamp>.txt`
each time it runs. Commit that log (and a few sample files from
`data/output/`) alongside this code as evidence the program executed
successfully against the full batch on an actual GPU.
